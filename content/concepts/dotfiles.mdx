Dotfiles are the hidden configuration files (`.bashrc`, `.zshrc`, `.bash_profile`, `.profile`) a shell reads automatically when it starts, used to set up aliases, environment variables, and prompt customization before you ever type a command. Which file gets read depends on the kind of shell session: a "login shell" (the first shell after logging in, or one started with `--login`) reads `.bash_profile`/`.profile`, while an ordinary interactive shell opened afterward (a new terminal tab, for instance) reads `.bashrc`.

This login-vs-non-login distinction is a frequent source of confusion — a setting placed in the wrong file might work in some terminals and silently not apply in others, depending on how each one happens to start its shell. Editing a dotfile also doesn't affect any shell session already running; you need to `source` the file again or open a new session for the change to take effect.
