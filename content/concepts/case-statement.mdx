`case` matches one value against a series of patterns, running the commands under the first pattern that matches — a cleaner alternative to a long `if`/`elif` chain when you're checking one value against several possibilities, especially when those possibilities are naturally expressed as glob patterns (`*.txt`, `img-*`) rather than exact string equality.

Each pattern is followed by `)`, then the commands to run, ending with `;;` to mark the end of that branch. A final `*)` branch, matching anything not caught earlier, serves the same role `else` plays in an `if` chain, and including one is good defensive practice so unexpected input doesn't silently fall through with no action taken at all.
