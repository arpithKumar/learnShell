An associative array maps arbitrary string keys to values, the same basic idea as a dictionary or hash map in other languages — declared with `declare -A name` before any keys can be assigned. Once declared, `name[key]=value` sets an entry and `${name[key]}` reads it back, with `${!name[@]}` expanding every key and `${name[@]}` expanding every value.

This is a genuinely newer feature than ordinary indexed arrays — bash didn't get associative arrays until version 4.0 in 2009, more than a decade after indexed arrays arrived. Forgetting the `declare -A` step is a common, quiet mistake: without it, `name[apple]=red` still "works" but creates a regular indexed array instead, where the string `apple` gets silently coerced to the number `0` as the index rather than acting as a real key.
