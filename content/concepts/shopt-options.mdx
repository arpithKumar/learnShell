`shopt` controls a separate set of bash-specific behavior toggles, distinct from the more POSIX-rooted options `set -o` manages. Common ones include `nullglob` (makes a glob with no matches expand to nothing instead of staying as the literal pattern text), `globstar` (enables `**` to match recursively through subdirectories), and `autocd` (typing just a directory name changes into it, no `cd` needed).

It's easy to expect every shell-behavior toggle to live under one unified mechanism, but bash genuinely splits them across two: `set -o` for the longer-established, more POSIX-aligned options (`errexit`, `nounset`, `pipefail`), and `shopt` for newer, bash-specific ones. `shopt -p` is the equivalent of `set -o` with no arguments — printing every currently configured option in a directly reusable form.
