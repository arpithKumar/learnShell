A function groups a sequence of commands under a single callable name, defined as `name() { commands; }`. Once defined, calling it by name runs that block, with any words after the function name available inside as `$1`, `$2`, and so on — the same positional-parameter convention a whole script uses for its own arguments, just scoped to the function call.

Functions don't have a `return value` in the way other languages mean it — `return N` sets the function's exit status (0–255), which is what `if` and `&&`/`||` check, not a value you capture directly. To actually get a computed value back out, the usual pattern is having the function `echo` it and capturing that with command substitution: `result=$(my_function)`. Variables a function creates are global by default unless explicitly marked `local`, which is the standard defensive habit for any function with its own working variables.
