`${!name}` performs one extra level of variable lookup: instead of returning the literal text stored in `name`, it treats that text as the name of *another* variable and returns that one's value instead. If `key="color_red"` and `color_red="crimson"`, then `${!key}` returns `crimson` — `key` points to a name, and indirection follows that pointer.

This shows up most often when generating variable names dynamically, like looping over a numbered or prefixed set of variables computed at runtime rather than known in advance. A separate but related form, `${!prefix*}`, instead lists every variable name that starts with a given prefix — genuinely useful for discovering what's been set, though it's easy to confuse with the single-name indirection form since both share the same leading `!`.
