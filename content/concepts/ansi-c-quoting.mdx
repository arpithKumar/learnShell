`$'...'` is a special quoting form where backslash escape sequences — `\n` for newline, `\t` for tab, `\\` for a literal backslash, and others borrowed from C string literals — are actually interpreted, unlike plain single or double quotes, which leave a literal backslash-n as two literal characters with no special meaning.

It's most useful when you need a real control character embedded directly in a string, such as a newline inside a single-line variable assignment, without resorting to an actual line break in the script's source or a separate `printf` call. Like several other shell quality-of-life features, it originated in ksh93 before bash and zsh both adopted it — it's not available in strict POSIX `sh`.
