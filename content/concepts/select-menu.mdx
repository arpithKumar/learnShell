`select` builds a simple numbered menu automatically: list the options after `in`, and it prints them numbered, prompts for a choice, and loops the body with the chosen value available as the loop variable — all without manually printing each option or parsing the user's numeric input yourself. It's commonly paired with a `case` statement inside the loop body to handle each possible choice, and an explicit `break` to exit once the user picks something like "quit."

The prompt shown before each choice is controlled by `PS3` (a less commonly known relative of `PS1`/`PS2`), and `$REPLY` holds whatever the user actually typed — useful for detecting and reporting an invalid selection rather than letting it silently loop back around. `select` is a bash/ksh extension, originating in ksh, not part of strict POSIX `sh`.
