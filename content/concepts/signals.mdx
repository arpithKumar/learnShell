A signal is a short, asynchronous notification sent to a running process — `Ctrl-C` at a terminal sends `SIGINT` ("please stop"), and `kill PID` sends `SIGTERM` by default ("please terminate") to a specific process by its ID. Most signals can be caught and handled by the receiving program, which is what lets a process clean up open files or temporary state before actually exiting rather than being cut off mid-operation.

`SIGKILL` (`kill -9`) is the notable exception — it terminates a process immediately at the operating-system level and cannot be intercepted, blocked, or handled, which makes it the last resort for a genuinely stuck process rather than the default choice. Inside a shell script, `trap 'commands' SIGNAL` registers a handler that runs when the script receives a given signal, commonly used to guarantee cleanup code runs even if the script is interrupted partway through.
