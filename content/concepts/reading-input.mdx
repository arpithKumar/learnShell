`read` captures a line of input — typed interactively, or piped/redirected in — into one or more variables. Its most commonly used options are `-p "prompt"` to display a prompt before reading, `-s` to read silently without echoing characters (the standard way to prompt for a password), and `-a name` to read an entire line into an array, one word per element.

`-r` is worth treating as a near-default habit: without it, `read` interprets backslashes in the input as escape sequences, which can silently eat characters or merge lines in ways that are rarely what you actually want. Like other shell input, `read`'s field-splitting behavior follows the same `IFS`-based word-splitting rules as everywhere else, which is why giving it multiple variable names splits one line of input across them.
