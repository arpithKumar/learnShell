Positional parameters are how a script or function receives its arguments: `$1`, `$2`, `$3`, and so on for each individual argument, `$#` for the total count, and `$0` for the script's own name (not an argument at all, just where it lives by convention). A function's positional parameters are separate from the enclosing script's — calling `myfunc a b` resets `$1`/`$2` inside that function to `a`/`b` for the duration of the call.

The two collective forms, `$@` and `$*`, both represent "all the arguments," but behave differently once quoted: `"$@"` expands to each argument as its own separate, correctly preserved word, while `"$*"` joins everything into a single string. This distinction matters enormously when forwarding arguments to another command — `"$@"` is almost always the correct choice.
