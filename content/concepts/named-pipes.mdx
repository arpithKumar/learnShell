A named pipe, created with `mkfifo`, is a FIFO (first-in-first-out) special file that behaves like an anonymous shell pipe (`|`) but exists as a real entry in the filesystem with its own name, rather than connecting only two commands written on the same command line. Anything written to it by one process can be read by another, even if those two processes weren't started together and have no direct parent-child relationship.

This makes named pipes useful for connecting separate, independently-started processes — one script writing data, another reading it whenever it happens to run — without either one knowing where the other lives, only the shared pipe's path. Unlike a regular file, a named pipe doesn't actually store data on disk; reading from it blocks until something writes, and writing to it blocks until something reads, the same blocking behavior an ordinary pipe has.
