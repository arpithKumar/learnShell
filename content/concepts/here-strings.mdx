A here-string, `command <<< "value"`, feeds a single string to a command's standard input — the simpler, one-line equivalent of a full `<<EOF ... EOF` here-document block, for the common case where you just need to hand a command one value rather than several lines of text. It's especially common paired with `read`, as a way to parse one line of data without needing an actual pipe or a separate file.

It accomplishes roughly the same thing as `echo "$value" | command`, but more efficiently — no extra `echo` process and no extra pipeline subshell are needed, since the shell hands the string directly to the command's input. Like process substitution, it's a bash/ksh/zsh feature absent from strict POSIX `sh`, and it arrived in bash noticeably later than the classic here-document syntax.
