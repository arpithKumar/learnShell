An array holds an ordered list of values under one variable name, declared with `name=(value1 value2 value3)` and indexed from zero. A single element is accessed with `${name[1]}`, while `${name[@]}` expands every element as its own separate word — the form you almost always want when looping over an array's contents, especially when an element might contain spaces.

Arrays are a bash/zsh feature rather than part of the strict POSIX shell standard, so a script that needs maximum portability (declared `#!/bin/sh`) generally can't assume they're available. Within bash or zsh scripts specifically, though, they're the standard way to collect a list of items — file paths, arguments, lines read from a command — before iterating over them with a `for` loop.
