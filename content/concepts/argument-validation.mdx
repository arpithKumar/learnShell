Validating arguments means checking, right at the start of a script, that it actually received what it needs — the right number of arguments, and ideally the right shape for each one — before using any of them. `if [ $# -lt 1 ]; then echo "Usage: ..." >&2; exit 1; fi` is the most common form: catch a missing argument immediately, print how the script should actually be called, and exit cleanly rather than letting some later line fail with a confusing, unrelated-looking error.

Checking the count alone only catches "nothing was passed" — it doesn't catch "the wrong kind of thing was passed." Pairing it with a shape check (a regex via `[[ =~ ]]`, an `-f` test for a file argument, or a `case` pattern for an expected set of values) catches a much wider range of real-world misuse before it has a chance to cause a confusing failure several lines deeper into the script.
