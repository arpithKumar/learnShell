The shebang is the literal first line of a script, starting with `#!` followed by the path to an interpreter — `#!/bin/bash`, `#!/usr/bin/env python3`, and so on. When a script is run directly as an executable file (`./script.sh`, with the executable permission bit set), the operating system reads this line first and launches that interpreter to run the rest of the file, rather than trying to execute the script's own text as a native binary.

It only matters for that direct-execution path — running `bash script.sh` or `python3 script.py` explicitly bypasses the shebang entirely, since you've already told the system which interpreter to use. `#!/usr/bin/env bash` is generally preferred over a hardcoded `#!/bin/bash` for portability, since it finds the interpreter via `$PATH` instead of assuming a fixed install location.
