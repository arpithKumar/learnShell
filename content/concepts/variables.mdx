A shell variable is a name bound to a value, created with a plain assignment like `name="Alice"` — no spaces around the `=`, since the shell parses that exact pattern as an assignment rather than a command. Once set, the value is retrieved by prefixing the name with `$`, as in `$name`, or `${name}` when it needs to be unambiguously separated from surrounding text.

By default, a variable only exists inside the current shell session or script — it isn't visible to programs the shell launches. `export` promotes a variable into the environment so child processes inherit it, which is the mechanism behind things like `$PATH` being visible to every command you run. Variables are untyped strings under the hood; arithmetic needs explicit syntax like `$((x + 1))` rather than relying on `+` to add numbers the way it would in a typed language.
