Beyond default values and prefix/suffix stripping, parameter expansion also supports string editing directly: `${var:offset:length}` extracts a substring by position, `${var/pattern/replacement}` replaces the first match of a pattern, and `${var//pattern/replacement}` (note the doubled slash) replaces every match instead of just the first.

These are bash/zsh extensions on top of the more minimal POSIX parameter-expansion feature set, so a strictly portable `#!/bin/sh` script can't rely on them — `cut`, `sed`, or `awk` are the usual fallback for substring and replace operations in that more constrained environment. Within bash specifically, though, these operators are fast and avoid spawning a separate process just to edit a string.
