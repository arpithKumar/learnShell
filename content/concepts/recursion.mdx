A recursive function calls itself, usually with a slightly smaller version of the original problem each time, until a base case is reached and the chain of calls finally stops and unwinds. Shell functions can do this — the example above computes a factorial by having `factorial` call itself with a decremented argument until it hits `1`.

In practice, shell scripting reaches for recursion far less often than languages built more explicitly around it. Each recursive call carries real overhead (a new function context, and command-substitution-based recursion like above forks an actual subshell per call), and most problems that look naturally recursive — walking a directory tree, for instance — usually have a more efficient iterative or `find`-based equivalent in shell. Bash even enforces a maximum nesting depth (`FUNCNEST`) specifically to stop a recursive function with a broken or unreachable base case before it runs away.
