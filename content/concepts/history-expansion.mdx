History expansion is shorthand for referencing pieces of previous commands without retyping them: `!!` expands to the entire previous command (classically used as `sudo !!` after forgetting `sudo` the first time), `!$` expands to the last argument of the previous command, and `!n` expands to the command at a specific position from `history`'s numbered list.

It's purely an interactive-shell convenience, expanded before the resulting command actually runs — appending `:p` to any of these (`!!:p`) prints what it would expand to without executing it, useful for double-checking before running something potentially destructive. Like job control, this `!`-based syntax traces back to the C shell, predating its later adoption into bash.
