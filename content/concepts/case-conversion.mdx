  - description: Lowercase an entire string

    output: "alice"
  - description: Capitalize just the first character
    input: 'name="alice"; echo "${name^}"'
    output: "Alice"

`${var^^}` uppercases an entire string, `${var,,}` lowercases it, and the single-character versions (`${var^}`, `${var,}`) affect only the first character — handy for normalizing user input or capitalizing a name, entirely inline without spawning a separate `tr` process. Bash 4.0 also supports targeting only characters matching a pattern, like `${var^^[aeiou]}` to uppercase just the vowels, though the plain whole-string forms cover the overwhelming majority of real use cases.

This is a bash-specific extension (4.0+), not part of POSIX parameter expansion, so it's unavailable both in older bash versions and in strict `sh` — `tr '[:lower:]' '[:upper:]'` remains the portable fallback when a script needs to support either of those.
