A here-document lets you write a multi-line block of literal text directly inline in a script and feed it to a command's standard input, without creating a separate file. The syntax is `command <<DELIMITER`, followed by the lines of text, ending with that same delimiter word (`EOF` is the common convention, though any word works) alone on its own line.

By default, variables and command substitution inside the block still expand, just like in double-quoted text — wrapping the delimiter in quotes (`<<'EOF'`) disables that and treats the whole block completely literally. This is genuinely useful for generating config files or multi-line messages inline in a script, and the related here-string (`<<<`) covers the simpler one-line case without needing the full block syntax.
