`PS1` controls what your interactive shell prompt looks like, built from a mix of literal text and special backslash-escaped codes — `\u` for username, `\h` for hostname, `\w` for the current working directory, and many more. Setting it in a dotfile like `.bashrc` is how most people end up with a prompt showing useful context (directory, git branch, exit status of the last command) instead of bash's plain default.

`PS2` is the related, less commonly customized prompt shown when a command continues onto a second line (typically just `> ` by default) — for instance after a line ending in a backslash, or in the middle of an unclosed quote. Building a genuinely full-featured prompt by hand in `PS1` gets unwieldy quickly once you want git status or conditional coloring, which is why dedicated prompt frameworks like starship exist as a popular alternative to writing the whole thing manually.
