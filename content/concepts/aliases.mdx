An alias is a simple text substitution defined for convenience — `alias ll='ls -la'` means typing `ll` afterward runs `ls -la` instead. It's purely a shorthand at the shell's command-entry level, expanded before anything else happens, with no real support for parameters the way a function has.

Aliases set interactively in a terminal disappear once that session ends, which is why persistent ones live in a dotfile like `.bashrc` instead. They're also intentionally limited in scope: once a command needs actual logic, argument handling, or anything beyond "replace this short word with this longer text," a shell function is the right upgrade rather than trying to stretch an alias further than it's built for.
