Beyond variables you set yourself, the shell maintains a handful of special ones automatically: `$$` is the current shell's process ID, `$!` is the process ID of the most recently started background job, `$0` is the script's own name, and `$RANDOM` (a bash/zsh extension) produces a new pseudo-random integer each time it's read.

These show up constantly in real scripts — `$!` paired with `kill` is the standard way to manage a background process you just launched, and `$$` is a common ingredient in generating a temp filename that won't collide with another running instance of the same script. None of these need to be declared; the shell populates them on its own as a normal part of running.
