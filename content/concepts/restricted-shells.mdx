A restricted shell (`bash -r`, or a shell symlinked/invoked as `rbash`) disables a specific set of operations that could otherwise be used to escape a confined environment: changing directories (`cd`), modifying `$PATH`, `$SHELL`, or `$ENV`, using command names containing a `/`, and redirecting output to new files, among a few others. It's intended for accounts that should be able to run a small, fixed set of commands and nothing more.

It's deliberately a partial defense, not a complete sandbox — a restricted shell still trusts whatever's already reachable through its starting `$PATH`, so real containment depends on pairing it with a genuinely minimal, carefully chosen set of available commands rather than expecting the restricted mode alone to prevent every possible escape.
