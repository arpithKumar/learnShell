Globbing is wildcard pattern matching against filenames: `*` matches any number of characters, `?` matches exactly one, and `[abc]` matches any single character in that set. Crucially, this expansion happens entirely inside the shell *before* the command runs — `rm *.log` doesn't tell `rm` about a wildcard, the shell first expands `*.log` into the literal list of matching filenames in the current directory, and `rm` simply receives that already-expanded list as its arguments.

This matters most when a pattern matches nothing: rather than disappearing, an unmatched glob is typically passed through to the command as the literal pattern text, which often produces a confusing "no such file" error referencing the wildcard itself. It's also why globbing is conceptually distinct from regular expressions used by tools like `grep` — they look superficially similar but follow different, much simpler matching rules.
