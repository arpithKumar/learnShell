Process substitution, `<(command)` or `>(command)`, makes a command's output (or input) appear as a filename rather than a stream — useful specifically for tools like `diff` or `comm` that expect two file arguments and have no concept of reading from a pipe directly. `diff <(ls dir1) <(ls dir2)` compares two directory listings without ever writing either one to a real temporary file.

It also solves a specific subshell problem: piping into a `while read` loop normally runs that loop in a subshell (so any variables it sets disappear afterward), but redirecting from `<(...)` instead — `done < <(command)` — keeps the loop in the current shell, so its variables persist as expected. This is a bash/zsh feature, not available in strict POSIX `sh`.
