`declare -n ref=varname` makes `ref` a nameref: a variable that, instead of holding a value directly, points at another variable by name — reading or writing `ref` actually reads or writes whatever variable it's bound to. Inside a function, this is the closest bash comes to pass-by-reference, letting a function genuinely modify a variable that belongs to its caller, rather than only being able to report a value back via `echo` and command substitution.

This is most useful for utility functions meant to update an existing variable in place — `add_one x` modifying `x` directly, instead of forcing every call site to write `x=$(add_one "$x")`. It's a comparatively recent bash feature (4.3, 2014), and like several other newer conveniences, it has no equivalent at all in strict POSIX `sh`.
