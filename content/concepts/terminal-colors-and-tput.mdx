Adding color to script output means sending the terminal special ANSI escape sequences embedded in the text itself — `\033[31m` switches to red, `\033[0m` resets back to normal. `tput` provides a more portable way to generate the same effect (`tput setaf 1` for red, `tput sgr0` to reset), looking up the correct sequence for the actual terminal type via the `terminfo` database rather than assuming every terminal understands identical raw ANSI codes.

Two practical habits matter here: always resetting formatting after use, since a forgotten reset can leave a user's terminal stuck looking colored or bold long after the script exits, and checking whether stdout is actually a terminal (`[ -t 1 ]`) before emitting any color codes at all — piping colored output into a file or another program embeds literal, meaningless escape characters in data that was never meant to be displayed directly.
