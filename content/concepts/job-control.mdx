Job control is the set of shell features for managing multiple commands within a single interactive session: starting one in the background with a trailing `&`, listing all running and stopped jobs with `jobs`, and switching a job between foreground and background with `fg`/`bg`. `Ctrl-Z` suspends whatever's currently running in the foreground, handing control back to the prompt without killing the suspended process.

By default, every job belongs to the terminal session that started it — closing that terminal sends a signal that typically terminates any jobs still running in it. `nohup command &` and `disown` are the two common ways around that: `nohup` insulates the command from that signal from the start, while `disown` removes an already-running job from the shell's job table so closing the terminal doesn't affect it.
