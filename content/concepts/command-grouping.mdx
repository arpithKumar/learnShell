Both `{ command1; command2; }` and `(command1; command2)` group multiple commands so they can be treated as a single unit — redirected to one file together, or piped into another command as a combined stream — but they differ in an important way: curly braces run the group in the *current* shell, so any variables it sets or directory changes it makes persist afterward, while parentheses run the group in a *subshell*, where those same changes disappear once it closes.

This makes parentheses the right choice when you specifically want isolation — `(cd /tmp && ls)` looks around in `/tmp` without permanently changing your actual current directory — and curly braces the right choice when you want the grouped commands to share state with the rest of the script, like redirecting several `echo` statements to one log file together.
