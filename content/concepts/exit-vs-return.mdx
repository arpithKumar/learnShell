`return` ends the currently executing function and hands control back to whatever called it, optionally setting the function's exit status with a number. `exit` is much more drastic — it terminates the entire script (or the whole interactive shell, if typed directly at a prompt), not just the function currently running.

Using `exit` inside a function by mistake is a real, easy-to-make bug: instead of that function simply reporting failure to its caller and letting the script decide what to do next, the entire script stops dead, often well before its actual intended ending point. `return` is almost always the right choice inside a function; `exit` belongs at the top level, when the script as a whole is genuinely done.
