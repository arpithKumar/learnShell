A shell builtin is a command implemented directly inside the shell's own code — `cd`, `echo`, `test`, `read`, and `export` are all builtins in bash. An external command, by contrast, is a separate executable file the shell locates via `$PATH` and launches as its own new process — `grep`, `ls`, and `curl` all work this way.

Some commands genuinely have to be builtins to work at all: `cd` changes the shell's own current directory, and a separate child process could never do that to its parent, only to itself. `type command` is the standard way to check which kind something is — useful since a few commands, like `echo`, exist as both a builtin and a separate program with the same name, and they can behave slightly differently depending on which one actually runs.
