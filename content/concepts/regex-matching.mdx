The `=~` operator, used inside `[[ ... ]]`, tests a string against a full regular expression rather than a simple glob pattern — `[[ "$str" =~ ^[0-9]+$ ]]` checks whether `$str` is entirely digits, something globbing alone can't express. It's a meaningfully different tool from `case` or glob-based tests: regex supports anchors, character classes, repetition counts, and capture groups that glob patterns don't have any equivalent for.

After a successful match, bash populates the `BASH_REMATCH` array automatically — index `0` holds the entire matched substring, and `1`, `2`, etc. hold whatever each parenthesized group in the pattern captured. This makes `=~` genuinely useful for pulling structured data (like a version number's individual components) directly out of a string without invoking a separate `grep` or `sed` process just to extract it.
