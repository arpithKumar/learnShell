`touch` has two uses that both follow from the same underlying idea: it
updates a file's "last modified" timestamp to the current time. If the
file doesn't already exist, that update has nowhere to apply, so it
creates a new, empty file instead — which is why `touch` is the
standard quick way to make an empty placeholder file.

If the file *does* already exist, `touch` leaves its contents
completely alone — only the timestamp changes. That's genuinely useful
on its own: some build tools and `make`-style systems decide whether to
rebuild something based on file timestamps, so `touch`-ing a file is a
quick way to force a rebuild without actually editing it.
