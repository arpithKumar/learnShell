`local` declares a variable that exists only within the function it's defined in, disappearing once that function returns. This matters because shell variables are global by default — a variable set anywhere inside a function, without `local`, leaks out and can silently overwrite a variable of the same name used elsewhere in the script.

For any function with internal working variables — loop counters, temporary values — declaring them `local` is the defensive habit that prevents that kind of cross-contamination between unrelated parts of a script that happen to reuse a common variable name.
