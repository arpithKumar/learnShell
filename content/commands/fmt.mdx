`fmt` reflows paragraphs of plain text to a consistent line width, the same basic idea as a word processor's "justify" or "wrap text" feature, but from the command line. Where `fold` wraps at a hard character count even mid-word, `fmt` is paragraph-aware — it reflows whole blocks of text while keeping words intact and respecting blank lines as paragraph breaks.

It's the right tool specifically for actual written prose — reformatting a block of text to a narrower or wider column, for instance — and the wrong tool for anything structured, like code or tabular data, where reflowing would break the format rather than improve it.
