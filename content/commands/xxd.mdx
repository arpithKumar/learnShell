`xxd` displays a file's exact raw bytes in hexadecimal, alongside the same bytes shown as ASCII characters wherever they're printable. It's a genuinely low-level tool, useful when you need to see precisely what's actually stored in a file rather than how some program chooses to interpret it.

This level of detail matters when debugging binary file formats, inspecting the exact bytes of network data, or confirming a file's format signature — many file types start with a specific, recognizable sequence of bytes that `file` checks for automatically, but `xxd` lets you verify directly with your own eyes.
