`lsblk` lists the block devices attached to a system — physical disks and the partitions on them — in a readable tree showing how they nest, along with their size and where each is mounted, if at all. It's purely read-only and informational, making it a safe first step before any disk operation.

Before partitioning a drive with `fdisk` or `parted`, or troubleshooting a mount issue, `lsblk` is the standard way to get oriented: confirming exactly which device name corresponds to which physical disk, since getting that wrong before a destructive operation can affect the wrong drive entirely.
