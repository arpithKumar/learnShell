`npm` (Node Package Manager) installs and manages dependencies for JavaScript and Node.js projects, and also runs custom scripts a project defines for tasks like building, testing, or starting a dev server. It's the standard entry point for working with almost any Node.js codebase.

`npm install` with no arguments is usually the very first command run after cloning a project — it reads `package.json`'s dependency list and downloads everything needed into a local `node_modules` folder. Adding a specific package name instead (`npm install express`) both installs it and adds it to that dependency list for next time.

The `-g` flag changes scope entirely, installing a package globally rather than into the current project — useful for command-line tools you want available everywhere, but easy to confuse with a regular project-scoped install if you're not paying attention to which one you actually need.
