`printf` prints text using a format string, the same concept found in C and many other languages: placeholders like `%s` (string) or `%d` (integer) in the format get replaced by the arguments that follow, in order. It gives far more precise control than `echo` — padding numbers with leading zeros, fixing decimal places, aligning columns of text.

The trade-off for that control is that `printf` does exactly what you tell it and nothing more — including not adding a newline at the end automatically. Every `printf` call that should end a line needs an explicit `\n` in the format string, which is also what makes its behavior consistent and predictable across different systems, unlike `echo`, whose default behavior can vary slightly.

For simple "just print this text" cases, `echo` is still the quicker option. `printf` earns its place the moment you need actual formatting — fixed-width fields, padded numbers, or precise decimal output.
