`nice` starts a command with an adjusted scheduling priority, letting it yield more or less CPU time to other processes than it would by default. It's the tool for running something CPU-intensive — a batch job, a large compile — without it competing aggressively for resources against everything else on the machine.

The niceness scale runs from -20 (highest priority) to 19 (lowest), and the naming is intentionally backwards from what "priority" might suggest: a "nicer" process (higher number) is more considerate, giving up CPU time more readily. `nice -n 19 ./job.sh` runs a job at the lowest priority, so it only uses spare CPU cycles instead of competing with anything else actively running.
