`sftp` opens an interactive file transfer session over the same secure, encrypted connection `ssh` uses, letting you browse a remote filesystem and transfer files back and forth — the secure, modern successor to plain FTP, which transmits everything unencrypted.

Once connected, it behaves like a small dedicated shell: `ls` and `cd` to navigate the remote filesystem, `get filename` to download, `put filename` to upload. For a single, scripted file copy, `scp` is usually faster to type; `sftp`'s interactive session earns its place when you want to look around a remote directory first before deciding what to transfer.
