`md5sum` computes a checksum — a short fingerprint — of a file's contents using the MD5 algorithm. Two files with identical content always produce the same checksum, and changing even a single byte produces a completely different one, which makes it useful for verifying a file wasn't corrupted or altered.

The classic use is checking a downloaded file against a checksum the publisher provides: if they match, the download is intact. MD5 itself is no longer considered secure against deliberate tampering — it's been demonstrated that two different files can be deliberately crafted to share the same MD5 checksum — so for anything where security (not just accidental corruption) matters, `sha256sum` is the modern equivalent worth reaching for instead.
