`seq` prints a sequence of numbers, one common use being to drive a loop a fixed number of times: `seq 1 10` prints 1 through 10, one per line, ready to feed into a `for` loop or anything else that wants a list of numbers.

With one argument it counts up to that number starting from 1; with two, it's start and end; with three, it's start, step, and end — `seq 0 2 10` counts from 0 to 10 in steps of 2. `-w` is a small but genuinely useful touch: it pads every number to the same width with leading zeros, which keeps output aligned when numbers range from single to double digits.
