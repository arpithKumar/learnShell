`su` switches the current terminal session to another user's identity, prompting for that target user's password to do so. Without an argument it defaults to switching to root, making `su -` (with the trailing dash for a full login shell) a common shorthand for becoming root.

It's a meaningfully different model from `sudo`: `su` requires knowing the target account's own password, while `sudo` runs a single command as another user using the current user's own password, checked against a permission list. Many systems favor `sudo` for that reason — it doesn't require sharing or knowing root's password directly.
