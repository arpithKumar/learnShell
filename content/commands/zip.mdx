`zip` creates `.zip` archives, the same cross-platform format that's built into Windows Explorer, macOS Finder, and most file managers — making it the more universally shareable option compared to `.tar.gz`, which assumes the recipient has Unix tools available.

Unlike `tar`, which needs a separate flag to add compression, `zip` compresses by default as part of bundling. The flag to remember is `-r` (recursive) — without it, zipping a folder only captures the folder entry itself, not the files inside it, which is a common first surprise.
