`tail` is `head`'s mirror image: instead of the beginning of a file, it
shows the end — by default, the last 10 lines. That makes it the
natural tool for checking what just happened in a log file, where the
most recent and most relevant entries are always at the bottom.

Its standout feature is `-f` ("follow"), which doesn't just print the
current end of the file and stop — it keeps the file open and streams
new lines to your terminal as they're written. This is the standard way
developers watch a server's logs live: start a process in one terminal,
run `tail -f` on its log file in another, and watch errors or requests
appear in real time as they happen.

Since `-f` runs indefinitely by design, it won't return your prompt on
its own — you stop it manually with `Ctrl+C` once you're done watching.
