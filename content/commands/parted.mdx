`parted` manages disk partitions with full support for the modern GPT partition table format, alongside the older MBR style that tools like `fdisk` are limited to. Its `print` command, run without changing anything, shows the current partition layout — the safe first step before any real modification.

One meaningful difference from `fdisk` is that many `parted` operations apply immediately as soon as they're entered, rather than being staged and requiring an explicit final write step — which means there's less of a built-in pause to double-check before a change actually takes effect on the disk.
