`ssh-keygen` generates a new public/private key pair for SSH authentication, replacing the need to type a password every time you connect to a server. The private key stays on your machine and is never shared; the public key gets copied to any server you want passwordless access to.

`ssh-keygen -t ed25519` is the modern recommended invocation — `ed25519` is a newer key type that's shorter and faster than the older RSA default many older guides still show, with no security trade-off. Once generated, `ssh-copy-id` is the easiest way to install the resulting public key on a remote server.

The single most important habit: the private key file (with no extension, just `id_ed25519`) must never be shared, emailed, or committed to a repository. Only the `.pub` file is meant to be distributed.
