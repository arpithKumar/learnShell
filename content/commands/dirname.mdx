`dirname` is `basename`'s complement: instead of returning the filename, it returns everything *except* the filename — the directory the file lives in. `dirname /a/b/c.txt` returns `/a/b`.

The two are frequently used together inside scripts that need to work with both pieces of a path separately — moving a file relative to its own directory, for instance, or constructing a new path alongside an existing one. Like `basename`, it's a purely textual operation with no awareness of whether the path actually exists on disk.
