`realpath` takes any path — relative, containing `..` segments, or pointing through a symlink — and resolves it down to the one canonical, absolute path that actually identifies that file or directory on disk. It removes all the ambiguity a path can otherwise have.

This matters most inside scripts: a relative path's meaning depends entirely on the current working directory when the script runs, which isn't always predictable. Converting it with `realpath` upfront gives you a fixed, unambiguous path to work with for the rest of the script, regardless of where it was launched from.
