`basename` takes a full file path and strips away everything except the final component — the filename itself, without any of the directories leading up to it. It's a small, purely textual operation: `basename /a/b/c.txt` returns `c.txt`, regardless of whether that file actually exists.

This is mostly useful inside scripts, where a variable might hold a full path but the script only needs the filename — for a log message, a renamed copy, or a comparison. Passing a second argument as a suffix strips that exact suffix too, which is a quick way to get a filename without its extension.
