`w` reports who's logged in to the system, similar to `who`, but adds an extra column showing what command each user's session is currently running. It's a quick way to see both *who* is connected and *what they're actively doing* in a single glance.

This makes it slightly more useful than `who` alone on a shared system when you specifically want to know whether someone else is mid-task before doing something that might affect them.
