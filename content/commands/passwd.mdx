`passwd` sets or changes a user's login password, prompting interactively for the new value without echoing it to the terminal. Run with no arguments, it changes the current user's own password; changing someone else's requires root privileges via `sudo`.

It's typically the second step after creating an account with `useradd`, since a freshly created account has no usable password until `passwd` is run for it.
