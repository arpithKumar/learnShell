`useradd` creates a new user account on a Linux system, typically as one step in provisioning a new account alongside setting up a home directory and login shell. It's a privileged operation requiring root access, usually run with `sudo`.

A freshly created account has no password set by default and can't log in until one is assigned with `passwd`. The `-m` flag is commonly used to also create a home directory, since without it the new account has nowhere to store personal files.
