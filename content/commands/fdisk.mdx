`fdisk` creates, deletes, and inspects partitions on a disk, working with the traditional MBR-style partition table (and to a lesser extent GPT). Run with `-l`, it's purely informational — listing the existing partition layout without changing anything, a safe way to confirm exactly what's on a disk first.

Its interactive editing mode, used to actually create or delete partitions, is genuinely destructive: writing changes can erase existing data on that device immediately. `parted` is the more modern alternative with better GPT support, but both demand carefully confirming the target device name before making any real change — partitioning the wrong disk by mistake is unrecoverable.
