`vmstat` ("virtual memory statistics") prints a compact summary of system activity — processes waiting for CPU, memory usage, swap activity, disk I/O — repeating at a fixed interval if you ask it to. It's denser and more script-friendly than `top`, designed for quickly spotting whether a system is CPU-bound, memory-bound, or I/O-bound.

Running `vmstat 2 5` prints five snapshots, two seconds apart, which is enough to see whether numbers are trending up, down, or holding steady — useful for diagnosing a performance problem in progress rather than relying on a single static reading.
