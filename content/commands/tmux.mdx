`tmux` is a terminal multiplexer: it runs multiple terminal panes and windows inside a single session, and that session keeps running in the background even after disconnecting, ready to be reattached to later exactly as it was left. It serves the same core persistent-session purpose as `screen`, but adds much richer support for splitting a window into multiple panes and managing several named sessions at once.

The basic workflow is starting a named session with `tmux new -s NAME`, working inside it, detaching with the prefix key (`Ctrl-b` by default) followed by `d`, and later reattaching from any terminal — local or remote — with `tmux attach -t NAME`. This combination makes it a staple for anyone regularly working over SSH on remote servers.
