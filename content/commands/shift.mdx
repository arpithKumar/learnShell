`shift` removes a script's first positional argument (`$1`) and renumbers the rest down by one — what was `$2` becomes the new `$1`, and so on. It's the standard mechanism for processing a variable number of arguments one at a time in a loop, without needing to track an index yourself.

The common pattern is a `while` loop that checks `$#` (the count of remaining arguments), handles `$1`, then calls `shift` before looping again — each iteration peels off and processes the next argument until none are left. It's foundational to how many real-world shell scripts parse flexible argument lists, often alongside `getopts` for named flags specifically.
