`brew` (Homebrew) is the most widely used package manager for installing command-line tools and applications on macOS, filling a gap the operating system itself doesn't cover — many common Unix tools referenced in tutorials, like `tree` or a newer version of `bash`, simply aren't installed by default and need `brew install` to add them.

Unlike `apt` on Linux, `brew` deliberately installs into a location your regular user account already owns, which is why it doesn't need `sudo` for normal operations — a conscious design choice that keeps system directories untouched.

`brew update` refreshes Homebrew's own package list, and `brew upgrade` then installs newer versions of whatever you already have — the same two-step pattern as `apt`, just without needing elevated privileges along the way.
