`cp` copies files, and the basic shape is always the same:
`cp SOURCE DESTINATION`. If the destination is an existing directory,
the source gets copied *into* it under its original name. If the
destination is a new filename instead, the copy is created with that
name — effectively letting you copy-and-rename in one step.

Copying a single file is the easy case. Copying a whole folder needs the
`-r` (recursive) flag, since `cp` otherwise has no instructions for what
to do with the files and subfolders a directory might contain — without
`-r`, it just refuses and tells you the source is a directory.

There's no built-in "are you sure?" by default: if the destination file
already exists, `cp` overwrites it immediately. The `-i` flag adds an
interactive confirmation prompt before that happens, which is worth
using any time you're not completely certain the destination is safe to
overwrite.
