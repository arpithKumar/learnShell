`free` reports how much physical RAM and swap space your system has, how much is in use, and how much is genuinely available for new processes. It's a quick way to check whether memory pressure is contributing to a system feeling slow.

`free -h` is the version almost everyone actually types — human-readable sizes instead of raw byte counts. The column worth paying attention to is "available," not "free": modern Linux systems use otherwise-idle memory for disk caching, which shows up as "used" but is actually reclaimable on demand, so "available" is the more accurate picture of what's really left to work with.
