`dig` ("domain information groper") queries DNS servers directly and shows exactly how a domain name resolves — its IP address, mail server records, name server records, and more, along with the full technical detail of the response.

For everyday use, `dig +short example.com` is the version worth knowing — it strips away dig's normally verbose diagnostic output and just prints the resolved IP address. The full output becomes useful specifically when troubleshooting DNS issues, where details like which name server answered and how long the result is cached for actually matter.
