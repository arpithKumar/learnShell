`pgrep` searches running processes by name and prints their PIDs, the same matching logic `pkill` uses but without taking any action — it's a pure lookup tool. It replaces the more verbose `ps aux | grep name` pattern with a single, more direct command.

It pairs naturally with `pkill`: run `pgrep` first to see exactly which processes a name pattern matches, confirm that's really what you want to affect, and only then reach for `pkill` with the same pattern to actually act on them.
