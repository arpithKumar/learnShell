When a file is too long to comfortably read all at once, `head` lets
you peek at just the beginning — by default, the first 10 lines. It's
a quick sanity check: confirming a CSV's header row looks right, or
seeing the start of a log file without scrolling through everything
that follows.

`head` is especially useful piped after another command rather than
used on a file directly. `ls -lt | head -n 5` lists files sorted by
modification time and then trims that down to just the 5 most recent —
a pattern that generalizes to almost any command that produces more
output than you actually want to look at.
