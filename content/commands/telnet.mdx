`telnet` opens a raw, unencrypted connection to a host and port, originally designed as a remote login protocol — a role `ssh` has long since taken over for any real use, since `telnet` transmits everything, including passwords, in plain text with zero encryption.

Where `telnet` still earns a place today is protocol debugging: connecting directly to a port and typing raw commands by hand to see exactly how a server responds, without any client library or tool interpreting the conversation for you. It's `nc`'s older, more protocol-aware cousin for that specific kind of low-level poking around.
