`stat` prints detailed metadata about a file that `ls -l` only partially shows: exact size in bytes, precise modification and access timestamps, the underlying inode number, and full permission and ownership details, all in one structured report.

It's the tool to reach for when you need to confirm something precise — did a `chmod` or `chown` actually apply correctly, exactly when was a file last modified down to the second, how many disk blocks does it actually occupy. `ls -l` is fine for a quick glance; `stat` is for when you need the exact answer.
