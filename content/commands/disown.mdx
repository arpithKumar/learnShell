`disown` removes a background job from your shell's job table, which has one specific practical effect: when the shell later closes and would normally send a hang-up signal to every job it still knows about, a disowned job is no longer on that list and keeps running.

It solves the same underlying problem as `nohup`, but from the opposite direction — `nohup` is set up *before* starting a command, while `disown` is applied *after*, to something already running that you've only now decided should survive the terminal closing. The trade-off is that once disowned, that job also drops off `jobs`, `fg`, and `bg`'s radar — you give up easy control over it in exchange for it persisting.
