`lsof` ("list open files") shows every file, device, and network connection currently held open by running processes, and which process holds each one. Because Unix treats network sockets as a kind of file handle internally, `lsof` doubles as one of the most direct tools for answering "what's using this port" — often faster to interpret than `netstat`'s broader connection listing.

`lsof -i :3000` is the version worth memorizing: it filters straight to whatever's bound to port 3000, showing the process name and PID you'd need to stop it with `kill`. Filtering by `-p` (a specific process) or `-u` (a specific user) narrows the same underlying view to exactly what you're trying to investigate.
