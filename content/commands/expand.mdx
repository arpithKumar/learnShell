`expand` converts tab characters in a file into an equivalent number of literal space characters. It exists because tabs render differently depending on the viewer or editor's configured tab width, which can make code or text look correctly indented in one tool and misaligned in another.

Running text through `expand` removes that ambiguity by replacing every tab with a fixed, explicit number of spaces — set with `-t` to match whatever convention your project actually uses, since the default of 8 is wider than most modern code style guides.
