`uptime` answers two questions in one short line: how long has this machine been running since its last reboot, and how busy is it right now, expressed as load averages over the last 1, 5, and 15 minutes.

A long uptime is a quick sanity check that a server hasn't unexpectedly restarted. The load averages take a bit more context to read — they roughly indicate how many processes are competing for the CPU at once, so what counts as "high" depends entirely on how many CPU cores the machine actually has.
