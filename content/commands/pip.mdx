`pip` installs and manages Python packages, the same fundamental role `npm` plays for Node.js. `pip install package-name` downloads and installs a single package; `pip install -r requirements.txt` installs everything a project lists as a dependency, which is typically the first command run after cloning a Python project.

The detail that trips up a lot of newcomers is virtual environments: running `pip install` directly installs into your system-wide Python, where every project's dependencies compete in the same space. The standard practice is activating a project-specific virtual environment first (`source venv/bin/activate`), so each project's dependencies stay isolated from every other project's.
