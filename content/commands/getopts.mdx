`getopts` parses the short, single-letter flags passed to a script — like `-v` for verbose or `-f filename` — following the same conventions used by most standard command-line tools. It's typically run in a `while` loop, processing one flag per iteration and reporting which letter it found.

In the option string passed to `getopts`, a letter followed by a colon, like `f:`, signals that flag expects an accompanying argument, which becomes available in the `$OPTARG` variable inside the loop. This is the standard, conventional way to give a shell script flag-based options rather than relying purely on positional arguments handled with `shift`.
