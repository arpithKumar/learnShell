`apt` (Advanced Package Tool) installs, updates, and removes system software on Debian-based Linux distributions like Ubuntu and Debian — it's the standard way most server and desktop software gets installed on those systems, instead of downloading and compiling things manually.

The two-step habit worth knowing is `apt update` followed by `apt upgrade`: the first refreshes the local list of what packages and versions are available (it doesn't install anything by itself), and the second actually installs newer versions of packages you already have. Running `upgrade` without first running `update` works against a possibly stale package list.

Because `apt` manages system-wide software, almost every command needs to run with `sudo` — a regular user account doesn't have permission to install or remove things that affect the whole system.
