`date` prints the current date and time, and with a format string, lets you shape that output into almost any structure you need — useful both for quick reference and for generating consistent timestamps inside scripts.

The format string starts with `+` and uses letter codes prefixed with `%`: `%Y` for a 4-digit year, `%m` for month, `%d` for day, and so on. `date +%Y-%m-%d` is a genuinely common pattern for building a sortable, timestamped filename, like `backup-$(date +%Y-%m-%d).tar.gz`.

One real platform gotcha: GNU `date` (standard on Linux) and BSD `date` (standard on macOS) support different flags for things like date math — a script written and tested on one won't necessarily run unmodified on the other.
