`wc` ("word count") tallies up a few basic statistics about its input:
how many lines, words, and bytes it contains. Run with no flags, it
prints all three at once, which can be more than you wanted if you were
only after one specific number.

By far the most common use, in practice, is `wc -l` — counting lines.
Because so many command-line tools produce one result per line, piping
their output into `wc -l` is a quick generic way to count results:
`ls | wc -l` counts files in a directory, `grep -r TODO ./src | wc -l`
counts matches across a codebase, and so on. It works as a fallback
counting mechanism even when a tool doesn't have its own dedicated
"count" flag.
