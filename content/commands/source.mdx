`source` reads a script and runs its commands directly in your current shell session, rather than starting a separate subprocess to run it in. The distinction matters because anything a normal script does — setting variables, changing directory, defining functions — disappears the moment that script's subprocess exits. `source`-ing it means those changes happen in your actual session and persist afterward.

This is exactly why editing your `.zshrc` or `.bashrc` and wanting the changes immediately, without closing and reopening your terminal, means running `source ~/.zshrc` rather than just executing the file. It's the same mechanism behind activating a Python virtual environment (`source venv/bin/activate`) — the activation script needs to modify your current shell's environment, which only `source` allows.
