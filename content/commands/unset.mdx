`unset` removes a variable (or, with `-f`, a function) from the shell's environment entirely, as opposed to merely setting it to an empty value. This distinction matters in scripts that check `${VAR:-default}` or test `[ -z "$VAR" ]` — an unset variable and one explicitly set to an empty string can be treated differently depending on exactly how a script checks for it.

It's most commonly used for cleaning up temporary variables once they're no longer needed, or for explicitly removing an exported environment variable so it no longer gets passed to subsequently launched programs.
