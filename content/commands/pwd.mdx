`pwd` stands for "print working directory," and it answers a question
that comes up constantly when working in a terminal: where, exactly, am
I right now? Unlike a graphical file manager, a shell gives you no
visual breadcrumb trail by default — `pwd` is that breadcrumb, on
demand.

It becomes especially important once you start writing shell scripts.
A script doesn't know where it'll be run from, so when it needs to
reference its own location reliably, capturing the result of `pwd` (or
a related technique) is often part of the setup.

Most of the time the plain command is all you need. The `-L` vs `-P`
distinction only matters if your path passes through a symbolic link —
`-L` shows the "logical" path including the symlink, while `-P` resolves
it down to the real underlying directory.
