`ifconfig` ("interface configuration") shows every network interface on the machine — Wi-Fi, Ethernet, loopback — along with each one's current IP address, status, and other low-level configuration. The most common reason to run it is simply finding your own machine's local IP address.

On modern Linux distributions, `ifconfig` has been officially superseded by the `ip` command (`ip addr` covers the same information), though `ifconfig` remains alive and well as the standard tool on macOS and BSD-derived systems, where there's no equivalent push to replace it.
