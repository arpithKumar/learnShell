`nc` ("netcat," sometimes nicknamed the network Swiss Army knife) reads and writes raw data directly over network connections, with no specific protocol baked in. That low-level flexibility makes it useful for quick connectivity tests, simple data transfer between two machines, and debugging exactly what a server actually sends back.

The most common everyday use is a quick port check: `nc -zv host port` reports whether a connection to that port succeeds, without sending or expecting any particular protocol's data — a lighter alternative to firing up `curl` just to confirm something is listening. For anything involving an actual protocol like HTTP, a purpose-built tool like `curl` is almost always the more practical choice, since it handles the protocol details `nc` deliberately leaves up to you.
