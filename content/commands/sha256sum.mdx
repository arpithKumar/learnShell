`sha256sum` computes a SHA-256 checksum of a file, the same basic concept as `md5sum` but using a cryptographic hash algorithm that's currently considered secure against deliberate tampering. It's the standard choice today for verifying that a downloaded file is exactly what the publisher intended.

Usage is identical to `md5sum`: compute a checksum, compare it against the one the publisher provides. The meaningful difference is trust — SHA-256 doesn't have MD5's known weaknesses, which is why operating system installers, package repositories, and security-conscious downloads publish SHA-256 checksums rather than MD5 ones.
