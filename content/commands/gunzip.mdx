`gunzip` is `gzip`'s mirror image: where `gzip` compresses a file into a `.gz`, `gunzip` decompresses it back. They're really the same underlying program with different default behavior — `gunzip file.gz` and `gzip -d file.gz` do exactly the same thing.

The most common scenario is unpacking something you downloaded: a `.gz` file lands in a folder, `gunzip` turns it back into the original plain file. As with `gzip`, the compressed version is removed once decompression finishes unless you tell it to keep it with `-k`.
