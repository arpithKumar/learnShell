`diff` compares two files and reports exactly where they differ — which lines were added, removed, or changed. It's the foundation underneath version control diffs, patch files, and code review tools, even when you're not aware it's running underneath them.

The output format you actually want almost every time is unified diff (`-u`): each differing section is shown with a few lines of surrounding context, additions marked with `+` and removals with `-`. This is the exact same format `git diff` produces and that the `patch` command consumes, which makes it worth defaulting to over plain `diff`'s harder-to-read default output.

`-r` extends the same comparison to entire directory trees, reporting which files differ (or exist only on one side) across two folder structures — useful for confirming a deployment matches a backup, or that a refactor didn't change more than intended.
