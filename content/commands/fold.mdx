`fold` wraps long lines of text so that none exceed a fixed width, breaking wherever necessary to stay under that limit. It's a blunt but reliable tool for fitting wide text — a long line in a log file, for instance — into a narrower terminal or printout.

By default it breaks strictly at the character limit, which can land mid-word; `-s` tells it to break at the nearest preceding space instead, producing output that reads more naturally. For wrapping actual prose with attention to sentence structure rather than a hard character count, `fmt` is the more appropriate tool.
