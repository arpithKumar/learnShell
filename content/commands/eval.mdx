`eval` takes a string and executes it as a shell command, as though that string had been typed directly at the prompt. This allows building up commands dynamically and running the result, which is occasionally genuinely necessary — but it comes with real risk attached.

The risk is that `eval` runs whatever text it's given with no inherent distinction between "code" and "data" — if any part of the string being evaluated traces back to user input or an untrusted source, it opens a straightforward shell injection vulnerability, where a crafted value runs commands the script never intended. It's worth treating `eval` as a tool of last resort, reaching for a function, array, or `case` statement first whenever one of those can do the same job more safely.
