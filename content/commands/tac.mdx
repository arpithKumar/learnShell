`tac` prints a file's lines in reverse order, so the last line appears first. It's `cat`'s name spelled backwards, and fittingly does almost the opposite-feeling transformation: same basic job of printing a file, but flipping the order top to bottom.

A practical use is viewing a log file with the most recent entries at the top instead of having to scroll to the bottom — `tac app.log` does that in one step. Don't confuse it with `rev`, which reverses the characters *within* each line rather than the order of the lines themselves.
