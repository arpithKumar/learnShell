`last` shows a history of logins to the system — who logged in, from where, when, and for how long — going back further than `who` or `w`, which only show who's currently connected right now. It's the tool for "who has been using this machine recently," not just "who's on it at this exact moment."

This makes it a useful basic security check on a shared or server system: reviewing recent login activity for anything unexpected, like a login at an unusual time or from an unfamiliar session. The history is limited by how far back the underlying log file goes, since it rotates and doesn't keep records indefinitely.
