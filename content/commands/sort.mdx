`sort` reorders the lines of whatever you give it. Left to its
defaults, it sorts alphabetically — more precisely, byte by byte —
which works perfectly for names and words but produces confusing
results for numbers: text sorting puts `"10"` before `"9"`, because as
characters, `'1'` simply comes before `'9'`.

That's exactly what the `-n` flag fixes: it tells `sort` to compare
values numerically instead of as raw text, so `9` correctly sorts
before `10`. Beyond plain ascending order, `-r` reverses it, and `-u`
removes duplicate lines as part of the same pass, instead of needing a
separate step.

`sort` is frequently the first half of a two-step pipeline with `uniq`,
since `uniq` can only catch duplicate lines that are directly adjacent
to each other — sorting first guarantees that any duplicates end up
next to one another, ready to be deduplicated or counted.
