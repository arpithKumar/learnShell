`csplit` splits a file into separate pieces at points matched by a pattern, rather than `split`'s fixed line count or byte size. It's the right tool when a file has natural, content-based breakpoints — chapter headings, record delimiters, a recurring marker line — and you want each section as its own file.

The syntax takes some getting used to, especially the repeat-count notation for "keep splitting on this pattern as many times as it matches." It's worth a test run against a copy of the file first, since a pattern that's slightly off can produce splits in places you didn't intend.
