`column` takes input with consistent fields — whitespace or a custom delimiter — and reformats it into a neatly aligned table, padding each column to match the widest value. It turns raw, unevenly-spaced text into something genuinely readable at a glance.

The flag to remember is `-t`, which tells `column` to treat the input as table data rather than just flowing words into a multi-column page layout (its default, less useful behavior). Paired with `-s` to set a custom separator, `column -t -s ','` is a fast way to sanity-check a CSV file's structure directly in the terminal.
