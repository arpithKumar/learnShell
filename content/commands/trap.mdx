`trap` registers a command to run automatically when a script receives a particular signal — Ctrl+C sends `INT`, a script finishing (for any reason) triggers `EXIT`, and so on. It's how a script defends itself against being interrupted mid-task without cleaning up after itself.

The most common, genuinely useful pattern is `trap 'cleanup_command' EXIT`, which guarantees that cleanup logic runs whether the script finishes normally, hits an error, or gets killed by the user — covering cases a simple "put cleanup code at the end of the script" approach would miss entirely, since that code never runs if something exits early.

`trap` can also be used to deliberately ignore a signal, by setting an empty command for it, which prevents a script from being interrupted at an inconvenient moment — though this is a sharper tool, worth using selectively rather than as a default habit.
