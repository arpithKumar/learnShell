`read` pulls in a line of input — typically from the user, but it can also read from a file or a pipe — and stores it into one or more shell variables. It's the basic building block for any script that needs to ask a question and act on the answer.

The most common pattern is `read -p "Prompt: " variable`, which shows a prompt and waits for input in one line. With `-s`, the typed characters aren't echoed back, which is the standard way scripts collect a password without displaying it on screen.

`read` can also split input across multiple variables: `read first last` on a line containing "Alice Smith" puts "Alice" into `first` and "Smith" into `last`, splitting on whitespace the same way the shell does everywhere else.
