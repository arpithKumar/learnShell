`mkdir` ("make directory") creates one or more new folders. In its
plainest form, it expects every folder in the path except the very last
one to already exist — `mkdir projects/new-app` only works if
`projects` is already there; `new-app` is the one piece it's allowed to
create.

The `-p` flag removes that restriction. It creates any missing parent
folders along the way, and — just as usefully — won't complain if the
target directory already exists. That combination makes `mkdir -p` the
safer default any time you're scripting, since a script that creates
directories should usually be able to run more than once without
erroring out on the second run.
