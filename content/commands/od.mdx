`od` ("octal dump") prints a file's raw bytes in octal, hexadecimal, or several other formats, serving the same basic purpose as `xxd` — inspecting exactly what's stored in a file at the byte level, rather than how a higher-level tool interprets it.

The name reflects its default behavior, showing bytes in octal, which most people find less intuitive than hexadecimal — `-x` switches to a more familiar hex view. `od` is the POSIX-standard tool for this job and guaranteed to be present even on minimal systems, while `xxd` (generally easier to read by default) is more of a GNU/common-tools convenience that isn't always preinstalled everywhere.
