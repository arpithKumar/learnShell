`ip` is the modern Linux tool for inspecting and configuring networking — interfaces, IP addresses, and routing tables — and is the officially recommended replacement for `ifconfig` (interfaces/addresses) and `route` (routing) on current distributions, both of which it supersedes with a more structured command set.

The structure follows an "object then action" pattern: `ip addr show` lists addresses, `ip link show` lists interfaces themselves, `ip route show` shows the routing table. It takes a little adjustment coming from `ifconfig`'s flatter style, but covers the same ground with a more consistent design across the different things it manages.
