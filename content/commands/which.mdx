`which` searches your `PATH` and reports the full path of the executable file that would run when you type a given command name. It answers a narrower but very common question: "where exactly is this program installed?"

This is especially useful when more than one version of a tool might be installed — `which -a python3` lists every match on your `PATH`, in the order the shell would try them, which helps explain why running `python3` picks up an unexpected version. For anything that isn't a plain executable file — aliases, shell functions, builtins — `which` won't see it at all; `type` is the broader tool for that.
