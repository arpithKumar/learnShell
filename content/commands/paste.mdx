`paste` takes multiple files and merges them line by line into columns — the first line of each file becomes one row, joined by a delimiter (a tab by default). It's the straightforward way to combine separate lists into a single table when they're already in the same order.

Because `paste` merges purely positionally (line 1 with line 1, line 2 with line 2, and so on), it has no concept of matching by a shared key the way a database join would — if the two files aren't already aligned, the result will look fine but be meaningless. For that kind of key-based merging, `join` is the right tool instead.
