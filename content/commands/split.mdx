`split` breaks one large file into a series of smaller pieces, either by a fixed number of lines (`-l`) or a fixed byte size (`-b`). It's useful when a single file is too large for some downstream tool or transfer limit to handle comfortably as one piece.

Each output file gets the prefix you provide plus an automatically generated alphabetic suffix — `split -l 1000 big.csv chunk_` produces `chunk_aa`, `chunk_ab`, and so on. Worth noting: `split` has no awareness of structured content like a CSV header row, so only the very first chunk will contain it unless you handle that separately.
