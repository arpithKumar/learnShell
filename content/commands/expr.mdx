`expr` evaluates a basic expression — arithmetic like addition and multiplication, or string operations like length and substring — and prints the result. Historically it was the standard way to do math in a shell script, since the shell itself couldn't.

Every part of the expression has to be its own separate, space-separated argument: `expr 5 + 3` works, `expr 5+3` doesn't (it's read as one literal string). That spacing requirement, plus needing to escape `*` so the shell doesn't glob-expand it first, is exactly why most scripts written today use bash's built-in arithmetic syntax, `$((expression))`, instead — it's simpler to write correctly and doesn't need a separate process. `expr` is still worth recognizing when you encounter it in older scripts.
