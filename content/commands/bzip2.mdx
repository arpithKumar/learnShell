`bzip2` does the same basic job as `gzip` — compress a single file — but using a different algorithm that generally produces smaller files at the cost of being noticeably slower, both to compress and decompress. It's the right choice when file size matters more than speed, like archiving something for long-term storage.

The command shape mirrors `gzip` almost exactly: compress in place, `-d` to decompress, `-k` to keep the original. Paired with `tar`, it's invoked via the `-j` flag (`tar -cjf archive.tar.bz2 ./folder`) instead of `tar`'s `-z` for gzip.
