`wait` pauses script or shell execution until a background job finishes, which is exactly what you need when a script kicks off several tasks in parallel (`task1 & task2 &`) and then needs to confirm both have completed before continuing — for example, before reading the output files they each produced.

Called with no arguments, it waits for every background job from the current shell to finish; given a specific job number or PID, it waits for just that one. It's the missing piece that turns "start things in parallel" from a fire-and-forget action into something a script can reliably build on.
