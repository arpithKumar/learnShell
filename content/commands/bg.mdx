If you've paused a running program with `Ctrl+Z`, it's now "stopped" —
not actively running, but not gone either, just frozen in place. `bg`
resumes it, letting it continue execution but in the background, which
hands your terminal prompt back to you in the same way starting a
command with a trailing `&` would have done from the start.

This is genuinely useful as a recovery move: you start something in the
foreground, realize partway through that it's going to take a while and
you want your terminal back, hit `Ctrl+Z` to pause it, then `bg` to let
it keep going without giving up your prompt. Check `jobs` afterward to
confirm it picked back up and is running as expected.
