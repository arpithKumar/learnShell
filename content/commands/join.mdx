`join` merges two files by matching a shared field between them, the same concept as a database join — rows with the same key from each file get combined into one. This is a real step up from `paste`, which only merges by line position with no awareness of whether the data actually corresponds.

The catch, and the reason `join` sees less everyday use than its usefulness would suggest, is that both input files must already be sorted on the join field. Forgetting that step is the most common reason `join` silently produces incomplete results — rows that should have matched simply don't, because the sort order assumption wasn't met.
