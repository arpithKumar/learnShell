Every terminal session has a concept of a "current working directory" —
the folder you're conceptually standing in right now. Most commands that
take a file path, like `ls` or `cat`, resolve relative paths (ones that
don't start with `/`) against this location. `cd` (change directory) is
how you move that pointer around.

The simplest form, `cd foldername`, moves into a subfolder of where you
already are. You can also jump to an absolute path from anywhere
(`cd /var/log`), or use `~` as a shortcut for your home directory
(`cd ~/Documents`). Running `cd` with zero arguments is itself a
shortcut — it always takes you home, which is convenient until you do it
by accident mid-task.

One small but genuinely useful trick: `cd -` toggles back to whichever
directory you were in immediately before your last `cd`. That makes it
easy to bounce between two folders — like a project's `src` and its
`tests` — without retyping either path.
